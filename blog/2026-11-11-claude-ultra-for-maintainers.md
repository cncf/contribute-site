Anthropic is providing CNCF with gift codes for project maintainers.
Each code gives one person **6 months of Claude Ultra** at no cost.

This post explains what the codes include, who can use them, and how to request
one.

<!-- truncate -->

## What's included

| Detail                | Value                                   |
| --------------------- | --------------------------------------- |
| **Plan**              | Claude Ultra                            |
| **Duration**          | 6 months per code                       |
| **Redemption window** | 365 days from when each batch is issued |
| **Cost**              | Free for the 6-month period             |

## How the 6 months work

- **Start:** The 6 months begin when you select **Redeem**, not when CNCF sends
  you the link. Redeem the code when you're ready to start using it.
- **End:** If you were on the Free plan before redeeming, your account returns
  to the Free plan at no charge when the 6 months end.

## Eligibility

This benefit is for **official CNCF project maintainers**.

- Eligibility is based on the maintainer information in your project's
  `.project` repository. If it needs updating, open a PR in that repository
  before applying. Learn more about the
  [`.project` metadata format](https://github.com/cncf/automation/tree/main/utilities/dot-project).

Anthropic also requires that you:

- Are 18 or older (the minimum age is higher in some countries).
- Are located in a
  [supported region](https://www.anthropic.com/supported-countries).
- Accept Claude's
  [Consumer Terms](https://www.anthropic.com/legal/consumer-terms) and
  [Usage Policy](https://www.anthropic.com/legal/aup). New users accept these
  when they sign up.

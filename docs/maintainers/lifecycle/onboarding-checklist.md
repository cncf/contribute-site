---
title: Maintainer Onboarding Checklist
description: A practical checklist for new CNCF project maintainers
---

## Access and Permissions

- [ ] Confirm your maintainer role and repository access.
- [ ] Verify access to the CNCF Service Desk.
- [ ] Verify access to the project's GitHub organization, repositories, and teams.
- [ ] Confirm access to required project communication channels.
- [ ] Check that you have the permissions needed for your maintainer responsibilities.
- [ ] If access is missing, contact the appropriate project administrator or use the CNCF Service Desk.


## Tools

- [ ] Set up GitHub access and notifications.
- [ ] Set up the project's required development tools.
- [ ] Verify access to CI/CD systems and project infrastructure.
- [ ] Review the CNCF services available to maintainers.


## Communication Channels

- [ ] Join the project's primary communication channel.
- [ ] Join relevant mailing lists or chat channels.
- [ ] Subscribe to important GitHub notifications.
- [ ] Learn where project decisions and announcements are posted.


## Documentation to Read

- [ ] Read the project's `CONTRIBUTING.md`.
- [ ] Read the project's governance documentation.
- [ ] Review maintainer duties and responsibilities.
- [ ] Review security and code of conduct guidance.
- [ ] Understand the project's issue, review, and release processes.

## People to Meet

- [ ] Meet the existing maintainers and project leads.
- [ ] Identify the people responsible for project governance and operations.
- [ ] Introduce yourself in the project's primary communication channel.
- [ ] Identify the appropriate contacts for technical, community, and administrative questions.

## First Tasks

- [ ] Review the current issue and pull request queues.
- [ ] Learn the project's review and merge workflow.
- [ ] Help with issue triage and contributor questions.
- [ ] Take ownership of a small, well-defined maintainer task.
- [ ] Identify areas where the project needs additional maintainer support.

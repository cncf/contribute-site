---
title: Change Affiliation
---

- Send a PR with updates to
  [cncf/gitdm](https://github.com/cncf/gitdm?tab=readme-ov-file#addingupdating-affiliation).
- Update your name and current affiliation in your
  [LFID profile](https://openprofile.dev/). CNCF uses this profile for the name
  and affiliation shown in the
  [generated maintainer list](https://github.com/cncf/foundation/blob/main/project-maintainers-.project.csv).
- Update the affiliation in your project's public maintainer or governance
  documentation. The LFID profile, project documentation, and CNCF maintainer
  list are separate records.
- For projects using the
  [.project maintainer process](https://github.com/cncf/automation/tree/main/utilities/dot-project),
  update project metadata only when the GitHub handle or team membership
  changes. Do not edit the generated
  [CNCF .project maintainer list](https://github.com/cncf/foundation/blob/main/project-maintainers-.project.csv).
- If your project is still on the
  [legacy maintainer list](https://github.com/cncf/foundation/blob/main/project-maintainers.csv),
  follow the project's existing update process for that list. Access to CNCF
- Service Desk, project maintainer mailing lists, and other CNCF services is
  controlled through the maintainer's GitHub handle in their project's
  `maintainers.yaml` and their information in their LFID profile.
